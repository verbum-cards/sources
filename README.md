# Cards (рабочее название «Слово»)

Приложение для заучивания иностранных слов карточками. Монорепозиторий: мобильное приложение, API, веб и бэкофис с общими контрактами и токенами дизайна.

```
apps/
  mobile/       Expo + React Native — само приложение
  api/          Node + PostgreSQL — вход, синхронизация, словарь, очередь LLM
  web/          Лендинг, политика конфиденциальности, удаление аккаунта; позже SEO-страницы
  backoffice/   Внутренний инструмент редактора: словарь, колоды, жалобы
packages/
  tokens/       Токены дизайн-системы → TS и CSS для всех приложений
  contracts/    Общие типы: модель данных, протокол синхронизации, API
data/           Открытые списки уровней CEFR и образец формата словаря
docs/           Продуктовые и технические документы — источник правды
.claude/        Агенты, скиллы и настройки Claude Code
.github/        Воркфлоу фоновой разработки, шаблоны issues и PR
scripts/        Служебные скрипты (метки GitHub)
```

Фоновая разработка через GitHub Issues — `docs/automation.md`.

Как начать: см. `docs/backlog/week-01.md`. Правила работы для Claude Code — в `CLAUDE.md`.

## Первый запуск с Claude Code

```bash
# 1. Распаковать архив, перейти в папку и создать репозиторий
cd cards
git init && git add . && git commit -m "Пакет передачи: документы, токены, контракты, стартовый код"
# (по желанию) создать приватный репозиторий на GitHub и сделать git push

# 2. Установить pnpm, если его нет
npm install -g pnpm

# 3. Запустить Claude Code в корне репозитория
claude
```

Первое сообщение для Claude Code:

> Прочитай CLAUDE.md и docs/. Потом возьми задачу T1.1 из docs/backlog/week-01.md: предложи план, дождись моего «ок» и сделай.

Дальше — по одной задаче из бэклога за сессию. Проверяйте результат на телефоне и отмечайте задачи в файлах бэклога.
