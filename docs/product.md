# Продукт

## Суть

Мобильное приложение для запоминания иностранных слов с интервальным повторением. Делает для Anki то же, что Zoom сделал для Skype: не добавляет функций, а убирает трение.

- Слово добавляется за 5 секунд: перевод, транскрипция, озвучка и пример подставляются автоматически из словаря на устройстве.
- Ничего не нужно настраивать: FSRS работает под капотом.
- Свои карточки бесплатно и без лимитов; платят за ИИ-автоматизацию (Premium).
- Колоды под жизненные ситуации (ресторан, как пройти, мнение и обсуждение) со словами и готовыми фразами.

## Аудитория беты

Самостоятельно изучающие английский русскоязычные 18–35 лет: путешествия, работа, переезд, экзамены, сериалы. Уровни A2–C1.

## Принципы

1. Мгновенный вход: до первой карточки не больше четырёх экранов.
2. «Просто работает»: надёжность и офлайн важнее функций.
3. Одно главное действие на экран.
4. Честность: бесплатные повторения навсегда, экспорт в Anki, никакого paywall в онбординге.

## Языки

Бета: русский → английский. Модель данных с первого дня поддерживает другие пары без дублирования (см. `data-model.md`).

## Объём беты (12 недель)

Онбординг (цель → уровень → первая сессия → вход → время и напоминания), добавление слова с автозаполнением и выбором значения, сессия повторения со знакомством с новым словом, лимит новых карточек, главный экран, 8 колод с контекстом для будущих уроков, синхронизация между устройствами, вход через Apple и Google, удаление аккаунта, экспорт .apkg и CSV, воронка онбординга в аналитике. Всё бесплатно.

## Не входит в бету

- Оплаты, Premium и лимит ИИ — недели 13–16, к публичному релизу.
- Вход по email — к публичному релизу.
- Импорт из Anki — v1.
- SEO-страницы слов и колод, шеринг колод по ссылке, камера, «Поделиться» из других приложений — v1.
- Субтитры, кабинет преподавателя, вторая языковая пара — v2.
- LLM-уроки по колодам — v2–v3 (но контекст колод заполняем уже сейчас).
- Грамматические курсы, ИИ-собеседник, десктоп-приложения.

## Метрики беты

- Время от первого запуска до первой карточки ≤ 60 с (медиана).
- Добавление слова ≤ 5 с (медиана).
- D7 retention ≥ 20% — критерий перехода к публичному релизу.
- Активация (гипотеза): прошёл первую сессию и добавил ≥ 3 своих слова за 24 часа.
