# Дизайн-система «Слово»

Полная версия с живыми превью компонентов: https://claude.ai/artifact/E2tJuGtdoy9qCnEhNRWARD. Значения токенов — в `packages/tokens/tokens.json` (единственный источник).

## Идея

«Чернила и маркер»: спокойная бумажная страница, почти чёрный текст и один яркий лаймовый маркер для главного. Второй акцент — мандарин (серия дней, «Не помню»). Две темы: светлая и тёмная, по умолчанию — как в системе.

## Правила цвета

- Фон экрана — `paper`; карточки, поля, таб-бар — `surface`; плитки и дорожка прогресса — `surfaceSunken`.
- Текст — `ink`, вторичный — `inkMuted`.
- Главная кнопка на `paper`/`surface` — `action` + `onAction` (чернильная в светлой теме, лаймовая в тёмной). Одна на экран.
- Панель главного действия дня — `panel` + `onPanel`, вторичный текст — `panelMuted`, кнопка внутри — `highlight` + `onHighlight`.
- `highlight` на светлом фоне — только заливка под тёмным текстом, никогда не цвет текста.
- Мандарин: подложка `signalSoft`, текст `signalInk`, иконка `signal`. Сплошной `signal` под текстом не используем.
- Изучаемое слово в примере — подложка `highlightSoft` под `ink`.
- Прогресс — `meter` на `surfaceSunken`.
- Разделители — `line`; границы контролов — `lineStrong`.

## Типографика

Unbounded (600) — слово на карточке, крупные числа, заголовки экранов. Onest (400/500/600) — всё остальное. Стили: `displayXl`, `displayL`, `displayWord`, `title`, `button`, `body`, `bodyS`, `label`, `caption`. Длинные слова переносятся, размер не уменьшается.

## Отступы, радиусы, движение

- Поля экрана 20, между блоками 16, внутри учебной карточки 24. Зоны нажатия ≥ 44, основные кнопки 48, главная 56.
- Радиусы: `lg` 24 — карточки и панели; `md` 14 — кнопки, поля, плитки; `pill` — чипы и прогресс; `sm` 6 — маркер в тексте.
- Тень только у учебной карточки, в тёмной теме её нет.
- Переворот карточки 280 мс ease-out; ответы уводят карточку за 220 мс; нажатие — сжатие до 98% за 120 мс; при «Уменьшить движение» — смена прозрачности 150 мс. Анимации — Reanimated.

## Компоненты (эталон — в дизайн-системе)

Button (primary / highlight / secondary / signal), WordInput, StudyCard, ReviewPanel, ProgressBar, Chip (default / streak / quiet), WordRow, TabBar. Иконки — lucide-react-native, линия 2, 20–22 pt.

## Тексты

На «ты», коротко, глаголы на кнопках, цифры вместо слов, без эмодзи, восклицательный знак — только для достижений.
