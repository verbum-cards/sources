# Какие данные собирает приложение

Источник для политики конфиденциальности, анкеты App Privacy (App Store) и формы Data safety (Google Play). Любой PR, который добавляет сбор данных, обновляет этот файл.

| Данные | Откуда | Зачем | Связаны с пользователем | Передаются третьим лицам |
|---|---|---|---|---|
| Email и идентификатор аккаунта Apple / Google | Вход | Аккаунт, синхронизация | Да | Нет |
| Карточки, ответы на повторения, профиль обучения (уровень, цели, время) | Приложение | Работа продукта, синхронизация | Да | Нет |
| Слова и уровень для генерации карточек | Приложение → LLM-провайдер | Автозаполнение редких слов | Нет (без идентификаторов) | Обработчик (LLM-провайдер) |
| События использования (воронка онбординга, сессии) | Аналитика | Улучшение продукта | Уточнить при выборе инструмента | Уточнить |
| Отчёты о сбоях | Инструмент отчётов о сбоях | Исправление ошибок | Уточнить | Уточнить |

Статус: черновик; уточняется при выборе инструментов аналитики и отчётов о сбоях.
