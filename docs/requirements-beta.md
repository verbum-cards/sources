# Требования в объёме беты

Нумерация совпадает с PRD. Здесь только то, что входит в бету; остальное — в PRD.

| ID | Требование | Критерии приёмки |
|---|---|---|
| FR-1 | Автозаполнение карточки: перевод, транскрипция, озвучка, пример | Слово из локального словаря → превью ≤ 300 мс без сети; с сервера ≤ 1 с |
| FR-2 | Ручное редактирование любых полей карточки | Любое поле меняется и сохраняется; общий словарь не меняется |
| FR-6 | FSRS без настроек | Новый пользователь проходит сессию, не открывая настроек |
| FR-7 | «Помню / Не помню» по умолчанию, 4 кнопки — по переключателю | Переключатель в настройках; по умолчанию 2 кнопки |
| FR-9 | Главный экран с панелью «Повторить (N)» | При наличии карточек к повторению панель — главный элемент |
| FR-10 | Офлайн и синхронизация | Без сети всё работает; после появления сети данные сходятся без потерь |
| FR-11 | Бесплатно без лимитов: свои карточки, повторения, озвучка, синхронизация, экспорт | Нет лимитов на число карточек и повторений |
| FR-15 | Экспорт .apkg и CSV | Файл .apkg открывается в Anki, медиа на месте |
| FR-21 | Лимит новых карточек в день по цели (5 / 10 / 15 минут → 5 / 10 / 15 новых) | Лишние новые ждут в очереди |
| FR-24 | Выбор значения многозначного слова | Самое частое значение выбрано заранее; карточка ссылается на sense |
| FR-27 | Удаление аккаунта из приложения с предложением экспорта | Удаляются все данные пользователя на сервере |
| FR-28 | Лист ожидания языков | Карточка на главном на 3-й день и пункт в профиле; ответы в аналитике |
| FR-31 | Локальный частотный словарь | Стартовый пакет 5 000 слов внутри приложения; 20 000 докачивается в фоне; аудио не в пакете |
| FR-36 | Знакомство с новым словом | Первый показ — сразу с переводом и примером; дальше — как вопрос |
| FR-38 | Пустое состояние главного после онбординга | Вместо панели «Повторить» — «Добавь слово, которое встретил сегодня» и 3 примера |
| FR-39 | Вход в существующий аккаунт и объединение прогресса | «Уже есть аккаунт» → главный за ≤ 2 экрана; при входе на шаге регистрации данные объединяются |
| FR-40 | Воронка онбординга в аналитике | События просмотра и завершения каждого шага с временем и источником |
| FR-41 | Вопрос о цели изучения | Первые 5 слов и стартовая колода — из тем выбранных целей |
| FR-42 | Уровень CEFR у значения и подбор «чуть выше уровня» | ≥ 95% значений основного словаря с уровнем; для B1 ≥ 60% предложений — B2 |
| FR-44 | Выражения (фразы) как тип карточек | В ситуационных колодах ≥ 30% карточек — фразы |
| FR-45 | Каталог колод с уровнями и прогрессом | 6 колод в бете; карточки уровня пользователя и выше; прогресс «X из Y» |
| FR-49 | Колода хранит контекст для будущих LLM-уроков | У всех колод заполнены ситуация, роли, регистр, словарь с уровнями, ветки, культурные заметки |

## Нефункциональные

- Холодный старт ≤ 1,5 с; переход к следующей карточке ≤ 100 мс.
- Ноль потерь данных при синхронизации; ежедневный бэкап базы.
- iOS 16.4+ (ограничение текущего Expo SDK), Android по минимуму Expo SDK; targetSdk ≥ 36.
- Светлая и тёмная темы; контраст текста ≥ 4,5:1; зоны нажатия ≥ 44 pt.
- Приватность: в LLM уходят только учебные данные, без личных.
