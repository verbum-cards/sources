# Пользовательские флоу

Всего 25 флоу в семи группах. Ядро продукта — ежедневный цикл «повторить → добавить → вернуться завтра»; всё остальное либо приводит в него, либо выводит из него деньги и новых людей.

Подробное описание — в отдельном файле на каждый флоу (ссылка в колонке «Файл» ниже). Не все флоу пока расписаны подробно — это явно указано внутри файла флоу; не додумывай отсутствующие шаги, попроси владельца описать флоу или пришли вопрос.

## Карта

*(схема: точки входа, активация, ежедневный цикл, ветки — исходник в Claude Docs, см. `docs/README.md`)*

Три точки входа сходятся в один онбординг; шеринг замыкает вирусную петлю, а Premium появляется только там, где пользователь уже получил пользу.
