# F19. Paywall и покупка

Триггер: лимит ИИ или премиум-функция · Этап: MVP · Требования: FR-12, FR-13 · Метрика: конверсия в платных

## Коротко

1. Триггер лимита или премиум-функции → экран Paywall с годовым тарифом по умолчанию.
2. Покупка через магазин снимает лимиты за секунды и возвращает туда, откуда пришёл пользователь, с уже выполненным действием.

## Подробно

1. Триггеры: 11-е ИИ-автозаполнение за день, нажатие на премиум-функцию (камера, субтитры, статистика), в A/B-тесте — седьмой день.
2. Экран: три преимущества Premium, годовой тариф выбран по умолчанию, месячный рядом, «Не сейчас» видна всегда, «Восстановить покупки» внизу.
3. Покупка через магазин → лимиты сняты за ≤ 5 сек.
4. Возврат туда, откуда пришёл, с уже выполненным действием: слово дозаполнено, камера открыта.

**Ветки:** оплата не прошла — сообщение магазина и повтор; подписка отменена — доступ до конца оплаченного периода, затем бесплатная версия без потери карточек.
