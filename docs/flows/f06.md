# F6. Добавление слова за 5 секунд (US-1)

Триггер: встретил слово · Этап: MVP · Требования: FR-1, FR-2, FR-12, FR-24, FR-30 · Метрика: карточек в день на пользователя

## Коротко

1. Поле «Новое слово» на главном; после 2 букв — до 3 подсказок из локального словаря с переводом.
2. Нормализация: регистр, пробелы, приведение к лемме («ran → run»), фразовые глаголы целиком.
3. Поиск: локальный словарь → сервер → LLM (если есть лимит ИИ; в бете лимита нет) → ручной ввод.
4. Превью: слово, транскрипция, аудио, перевод, пример с выделенным словом; у многозначного — чипы значений, самое частое выбрано.
5. «Добавить карточку» → строка «Добавлено · Отменить» на 5 с, фокус остаётся в пустом поле.

Ветки: дубликат («Уже в твоих карточках»), опечатка («Возможно, …?»), русское слово (варианты английских), фраза из 4+ слов (выбор слова), несуществующее слово («Не нашли», ручной ввод), нет сети (черновик, дозаполнится позже).

Бюджет: превью ≤ 300 мс из локального словаря; медиана от начала ввода до карточки ≤ 5 с.

## Подробно

Цель: от открытия приложения до сохранённой карточки — не больше 5 секунд и двух касаний после ввода. Главное решение, которое это делает возможным: **частотный словарь лежит прямо на телефоне**, поэтому превью появляется мгновенно и без сети, а сервер и LLM нужны только для редких слов.

**Бюджет времени**

| Шаг | Что делает пользователь | Что делает приложение | Бюджет |
| --- | --- | --- | --- |
| 1 | Открывает приложение или быстрое действие «Добавить слово» | Холодный старт; из быстрого действия — сразу поле с клавиатурой | ≤ 1,5 с |
| 2 | Печатает 2–3 буквы | Подсказки из локального словаря под полем | ≤ 100 мс на букву |
| 3 | Тапает подсказку или Enter | Нормализация и поиск → превью | ≤ 300 мс локально, ≤ 1 с с сервера |
| 4 | Смотрит превью, жмёт «Добавить» | Карточка сохранена локально, поле очищено для следующего слова | ≤ 100 мс |

**Основной путь**

1. **Вход.** Поле «Новое слово» на главном экране (MVP); быстрое действие на иконке и виджет (v1); кнопка «Добавить новые слова» на итоге сессии.
2. **Ввод с подсказками.** После двух букв под полем до трёх подсказок с переводом: «serendipity — счастливая случайность». Тап по подсказке сразу открывает превью.
3. **Нормализация.** Пробелы и регистр убираются; форма приводится к лемме с подсказкой («ran → run»); фразовые глаголы (give up) остаются целыми.
4. **Превью.** Слово, транскрипция, кнопка аудио, перевод и один пример с выделенным словом. У многозначного слова — чипы значений, самое частое уже выбрано, поэтому лишнего касания нет (FR-24).
5. **Добавление.** Одно касание «Добавить карточку» → карточка в очереди новых и в «Недавно добавлены», внизу на 5 секунд строка «Добавлено · Отменить». Фокус остаётся в пустом поле — можно сразу вводить следующее слово.
6. **Когда карточка попадёт в сессию.** Сегодня, если дневной лимит новых не исчерпан (FR-21); иначе в строке подтверждения пишем «Появится в повторении завтра».

**Откуда берётся перевод**

*(схема: добавление слова · 4 проверки, 3 источника перевода)*

Большинство слов должны находиться уже на первой проверке — это и даёт «5 секунд» и работу без сети. Карточки из LLM помечаются как непроверенные и попадают в очередь проверки словаря.

**Ветки и особые случаи**

| Ситуация | Что видит пользователь | Почему так |
| --- | --- | --- |
| Слова нет на устройстве, есть на сервере | Скелетон карточки → превью за ≤ 1 с | Редкие слова не храним на телефоне |
| Слова нет нигде, лимит ИИ есть | Скелетон с подписью «Составляем карточку…», превью за ≤ 5 с | Считается в дневной лимит (FR-12); результат сохраняется для всех |
| Лимит ИИ исчерпан | Карточка с пустым переводом для ручного ввода и строка «Автозаполнение без лимита — в Premium» | Не блокируем добавление и не открываем модальный paywall |
| Нет сети и слова нет на устройстве | «Сохранили — перевод подтянем, когда появится сеть» | Слово не должно потеряться |
| Слово уже есть | «Уже в твоих карточках, повторение через 3 дня» + «Повторить сейчас» и «Другое значение» | Повторный ввод — сигнал, что слово забывается (FR-30) |
| Опечатка | «Возможно, serendipity?» одной кнопкой | Исправление в одно касание (FR-30) |
| Введено русское слово | «Случайность» → варианты chance, coincidence, serendipity с оттенками смысла | Часто знают смысл, но не слово; работает через концепты модели данных |
| Введена фраза из 4+ слов | Слова фразы чипами: выбери нужное; фраза станет примером | Карточка — одно значение, фраза — контекст |
| Имя собственное или несуществующее слово | «Не нашли такого слова» + «Добавить вручную» | LLM не выдумывает перевод для несуществующих слов |
| Перевод не понравился | Тап по переводу → редактирование на месте, без отдельного экрана | Личная правка не меняет общий словарь |

**Состояния экрана:** пустое поле → ввод с подсказками → загрузка (скелетон) → превью → выбор значения → успех с отменой; плюс дубликат, черновик без сети и «не нашли».

**Аналитика**

| Событие | Параметры | Зачем |
| --- | --- | --- |
| word_input_started | точка входа | Начало отсчёта времени |
| preview_shown | источник (устройство, сервер, LLM), задержка в мс | Доля локальных попаданий и скорость |
| card_created | время от начала ввода, были ли правки, выбрано ли другое значение | Главная метрика флоу |
| card_undone | через сколько секунд | Ошибки в превью |
| duplicate_shown, typo_suggested, ai_limit_hit | — | Частота веток |

**Метрики успеха:** медиана от word_input_started до card_created ≤ 5 с; попадание в локальный словарь ≥ 90% вводов; доля карточек без правок — признак качества словаря.

**Критерии приёмки**

- Слово из локального словаря, сеть выключена → превью за ≤ 300 мс, карточка сохраняется и синхронизируется после появления сети.
- Многозначное слово → самое частое значение выбрано заранее, карточка создаётся одним касанием.
- После «Добавить» фокус в пустом поле, в течение 5 с доступна отмена.
- Исчерпанный лимит ИИ не блокирует добавление и не открывает модальное окно.
- Слово, введённое без сети и без локального перевода, сохраняется черновиком и дозаполняется автоматически.

**Новые требования из этого флоу:** FR-31 локальный частотный словарь на устройстве, FR-32 подсказки при вводе, FR-33 поиск по русскому слову, FR-34 отмена добавления, FR-35 быстрое действие и виджет — см. таблицу в конце `docs/flows/README.md`.
