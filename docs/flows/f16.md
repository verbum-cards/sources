# F16. Шеринг колоды

Триггер: кнопка «Поделиться» · Этап: v1 · Требования: FR-16, FR-25 · Метрика: вирусный коэффициент

## Коротко

1. Колода → «Поделиться» → ссылка, получатель открывает превью в браузере без аккаунта.
2. «Сохранить прогресс в приложении» → установка → после регистрации колода и прогресс уже на месте.

## Подробно

1. Колода → «Поделиться» → ссылка и системное меню отправки.
2. Получатель открывает её в браузере: название, автор, число слов и первые 10 карточек без аккаунта.
3. «Сохранить прогресс в приложении» → магазин → установка.
4. После регистрации колода и прогресс уже в приложении (отложенная глубокая ссылка, FR-25).

**Ветки:** приложение уже стоит — колода открывается сразу; автор удалил колоду — понятный экран и похожие колоды из каталога.
