# F10. Сессия повторения

Триггер: кнопка «Повторить» или уведомление · Этап: MVP · Требования: FR-6, FR-7, FR-9, FR-21 · Метрика: завершённые сессии

## Коротко

1. «Повторить» → очередь: просроченные, затем новые в пределах дневного лимита.
2. Новая карточка — знакомство (сразу с переводом). Повторная — слово и транскрипция → «Показать перевод» → «Не помню» / «Помню».
3. FSRS пересчитывает интервал; «Не помню» возвращает карточку в эту же сессию через несколько карточек.
4. Конец → итог: сколько карточек, доля верных, серия, что вернётся сегодня, прогноз на завтра.

Выход посреди сессии сохраняет прогресс. Всё работает без сети.

## Подробно

1. «Повторить» → очередь: сначала просроченные, затем новые в пределах дневного лимита (FR-21).
2. Карточка: слово, транскрипция, кнопка аудио.
3. «Показать перевод» → перевод и пример.
4. «Не помню» или «Помню» → FSRS пересчитывает интервал → следующая карточка.
5. Конец очереди → итог (F11): слова, доля верных, серия, предложение добавить слова.

**Ветки:** выход посреди сессии — прогресс сохранён, на главном «Осталось 12»; нет сети — всё работает, синхронизация потом; «Не помню» — карточка вернётся в этой же сессии через несколько карточек; ошибка в карточке — «Сообщить об ошибке» из меню карточки; слово слишком лёгкое — «Знаю это слово» убирает его из повторений (FR-22).
