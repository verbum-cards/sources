# F22. Удаление аккаунта

Триггер: профиль · Этап: MVP · Требования: FR-27, NFR-3 · Метрика: —

## Коротко

Профиль → «Удалить аккаунт» → предложение экспорта → предупреждение об активной подписке (если есть) → подтверждение → полное удаление данных.

## Подробно

1. Профиль → «Удалить аккаунт».
2. Предложение сначала скачать карточки (.apkg).
3. Если есть активная подписка — напоминание, что её отменяют в магазине.
4. Подтверждение → удаление всех данных (NFR-3).
