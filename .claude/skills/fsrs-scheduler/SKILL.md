# Планировщик повторений (FSRS)

Библиотека — `ts-fsrs`; перед использованием сверься с её актуальным API. Параметры FSRS — по умолчанию; персональная оптимизация параметров — после беты.

## Состояние карточки

- Источник правды — `review_log` (только добавление). Состояние FSRS (stability, difficulty, due, state) — **производное**: пересчитывается повтором журнала через планировщик и кешируется в локальной базе.
- Кеш пересчитывается после синхронизации, если пришли ответы с другого устройства.

## Кнопки → оценки

| Режим | Кнопка | Оценка FSRS |
|---|---|---|
| По умолчанию (2 кнопки) | «Не помню» | Again |
| | «Помню» | Good |
| Расширенный (4 кнопки) | «Не помню» / «Трудно» / «Помню» / «Легко» | Again / Hard / Good / Easy |

## Знакомство с новым словом (FR-36)

- Первый показ новой карточки — сразу с переводом и примером; кнопки «Знаю это слово» и «Дальше».
- Знакомство **не пишется** в FSRS как оценка. Карточка получает состояние `learning` и снова появляется **в этой же сессии** через 3–5 карточек уже как вопрос — это её первая оценка FSRS.
- «Знаю это слово» переводит карточку в `known`: она исключается из повторений (FR-22), вместо неё берётся следующая новая. Действие можно отменить в карточке слова.

## Очередь сессии

1. Просроченные карточки на повторение (`due ≤ сейчас`), по возрастанию `due`.
2. Карточки в `learning` с наступившим сроком.
3. Новые — не больше остатка дневного лимита, в порядке добавления (сначала свои слова, потом из колод).
4. «Не помню» — карточка возвращается в эту же сессию через 3–5 позиций (независимо от интервала FSRS в минутах).

Сессию можно прервать в любой момент; ответы уже в журнале, прогресс не теряется.

## Дневной лимит новых (FR-21)

- `user_profile.new_per_day`: 5 / 10 / 15 по времени в день.
- Сутки — по местному времени устройства; граница — местная полночь. При смене часового пояса сутки определяются текущим поясом.
- Лимит считается по числу новых карточек, **впервые показанных** за сутки (знакомство считается показом).
- Колода в режиме «Учить быстрее» (FR-46, после беты) повышает лимит только для своих карточек.

## Возвращение после перерыва (после беты, FR-23)

При > 100 просроченных — порция на сегодня ≤ 30, самые слабые (наименьшая stability) — первыми; остальные распределяются на следующие дни.

## Обязательные тесты

- Отображение кнопок в оценки в обоих режимах.
- Знакомство не создаёт записи FSRS; первая оценка — при повторном показе.
- Лимит новых: исчерпание, перенос на завтра, полночь, смена часового пояса.
- Возврат «Не помню» в ту же сессию.
- Пересчёт состояния из журнала даёт тот же результат, что пошаговое обновление.
