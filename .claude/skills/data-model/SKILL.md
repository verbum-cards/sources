# Модель данных

Полное описание — `docs/data-model.md`; типы — `packages/contracts/src/index.ts`. Этот скилл — инварианты и чек-лист.

## Инварианты (нарушение = ошибка)

1. **Уровень CEFR — у `sense` и `expression`**, не у лексемы.
2. **Карточка ссылается на `sense` или `expression`** (`item_type` + `item_id`), не на лемму.
3. **Языковая пара — настройка пользователя.** Контент хранится по языкам; связи между языками — через `concept`. Нельзя заводить таблицы или поля «на пару языков».
4. **Все пользовательские данные — с `user_id`.** Идентификаторы пользовательских записей — UUID v7, создаются клиентом.
5. **Общий контент неизменяем пользователями.** Личные правки — `card.overrides`.
6. **`review_log` только добавляется.** Состояние FSRS — производное.
7. **Удаление пользовательских данных — пометка `deleted_at`**, физически — только при удалении аккаунта.
8. **Контент, созданный LLM, имеет статус `unverified`** до проверки редактором и источник (`source`).
9. **Официальная колода обязана иметь `context`** (ситуация, роли, регистр, ветки, культурные заметки — FR-49).

## Где что живёт

| Что | Где |
|---|---|
| Общие типы и схемы | `packages/contracts` — единственное место |
| Серверная схема и миграции | `apps/api` |
| Локальная схема и миграции | `apps/mobile/src/db` |
| Пакет словаря на устройстве | отдельный файл SQLite, собирается конвейером (`apps/api/scripts`) |

## Чек-лист изменения модели

- [ ] Есть согласованный план архитектора (`needs-design` → `<!-- design -->`).
- [ ] Тип обновлён в `packages/contracts`; приложения используют его, а не свои копии.
- [ ] Серверная миграция: только вперёд; добавление → перенос данных → удаление старого отдельной миграцией.
- [ ] Локальная миграция: версия `user_version`, в транзакции, проверена на базе предыдущей версии с данными.
- [ ] Синхронизация: если поле синхронизируется — `schema_version` операций и приведение старых версий (скилл `sync-protocol`).
- [ ] Экспорт .apkg / CSV учитывает новое поле, если оно видно пользователю.
- [ ] `docs/data-model.md` обновлён; при необходимости — запись ADR.
- [ ] Тесты миграций и новых запросов.
