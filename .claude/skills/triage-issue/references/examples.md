# Примеры разборов

## Пример 1. Задача готова к работе

**Issue:** «Лимит новых карточек в день». Текст: «Нужно, чтобы новые карточки не сыпались все сразу».

```markdown
<!-- triage -->
**Разбор задачи**

Связано: FR-21, флоу F10 (шаг 1), docs/data-model.md → user_profile.new_per_day
Область: mobile · Тип: feature · Размер: M · Неделя: 02 · Приоритет: p1

**Критерии приёмки**
- [ ] В сессию попадает не больше `new_per_day` новых карточек за местные сутки
- [ ] Лишние новые карточки остаются в очереди и появляются на следующий день
- [ ] Счётчик сбрасывается в местную полночь, в том числе после смены часового пояса
- [ ] Добавление слова после исчерпания лимита показывает «Появится в повторении завтра»

**Как проверить на телефоне**
1. В профиле выбрать 5 минут (лимит 5)
2. Добавить 8 слов, пройти сессию — новых ровно 5
3. Перевести время устройства на следующий день — в сессии оставшиеся 3

**Тесты**
- Юнит-тесты очереди: лимит, перенос, полночь, смена часового пояса

**Статус:** готово к работе — ждёт метку `ready`.
```

## Пример 2. Нужен план архитектора и вопрос

**Issue:** «Хочу, чтобы можно было добавлять свою картинку к карточке».

```markdown
<!-- triage -->
**Разбор задачи**

Связано: FR-2 (правка полей карточки); новое поле в docs/data-model.md → card.overrides
Область: mobile · Тип: feature · Размер: M · Неделя: — · Приоритет: p2

Задача меняет модель данных (картинка в личной надстройке карточки) и синхронизацию: файлы не передаются в текущем протоколе, только поля. Нужен план архитектора: где хранить изображения, как синхронизировать, как экспортировать в .apkg.

**Вопросы**
1. Нужно ли это в бете, или можно после публичного релиза? В FR беты картинок нет.
2. Картинка — только из галереи или ещё поиск по словарю?

**Статус:** нужны ответы на вопросы выше и план архитектора (`needs-design`).
```

## Пример 3. Дробление зонтика

**Issue:** «Сделать онбординг» (без деталей).

```markdown
<!-- triage -->
**Разбор задачи**

Связано: флоу F1, FR-36, FR-38, FR-39, FR-40, FR-41, прототип «Онбординг»
Область: несколько · Тип: feature · Размер: L · Неделя: 08–09 · Приоритет: p1

Задача охватывает семь экранов, вход и аналитику — разбита на подзадачи:

**Подзадачи**
- [ ] #… 8.1 Экраны приветствия, цели и уровня (mobile, M)
- [ ] #… 8.2 Первая сессия в режиме знакомства со стартовыми словами по цели и уровню (mobile, M)
- [ ] #… 8.3 Вход через Apple и Google после первой сессии и привязка локального прогресса (sync, M, needs-design)
- [ ] #… 8.4 Экран времени и напоминаний, разрешение на уведомления (mobile, S)
- [ ] #… 8.5 Продолжение онбординга с прерванного шага (mobile, S)
- [ ] #… 8.6 События воронки онбординга (mobile, S)

**Статус:** зонтик; в работу идут подзадачи.
```
