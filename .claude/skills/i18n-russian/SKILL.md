# i18n и русский язык

Язык интерфейса в бете один — русский, но **все** строки идут через i18n: так добавление второго языка не потребует правок компонентов.

## Инструменты (предложение)

i18next + react-i18next. Формы множественного числа — через `Intl.PluralRules` (суффиксы `_one`, `_few`, `_many`, `_other`). Если движок JavaScript на устройстве не поддерживает `Intl.PluralRules`, подключи полифил (`@formatjs/intl-pluralrules` с локалью `ru`) — проверь это в первой задаче по i18n.

## Ключи

- Формат: `экран.блок.элемент` на английском: `home.review.button`, `session.summary.title`.
- Один ключ — одна фраза целиком. **Никогда не склеивай** строки из частей: порядок слов в других языках другой.
- Подстановки — именованные: `"home.review.minutes": "≈ {{count}} мин"`.
- Файлы: `src/i18n/ru/<экран>.json`; общие слова — `common.json`.

## Множественное число

У русского три формы плюс дробная:

```json
{
  "cards_one": "{{count}} карточка",
  "cards_few": "{{count}} карточки",
  "cards_many": "{{count}} карточек",
  "cards_other": "{{count}} карточки"
}
```

`one`: 1, 21, 31… (кроме 11); `few`: 2–4, 22–24… (кроме 12–14); `many`: 0, 5–20, 25–30…; `other`: дробные (1,5 карточки). Проверяй 0, 1, 2, 5, 11, 12, 21, 22, 25, 111.

Частые слова: карточка, слово, день, минута, колода, повторение — для каждого все формы.

## Даты, время, числа

Только через `Intl` с локалью `ru-RU`: `Intl.DateTimeFormat('ru-RU', { weekday: 'long', day: 'numeric', month: 'long' })`, `Intl.NumberFormat('ru-RU')` (пробел как разделитель тысяч). Не форматируй вручную. Первая буква дня недели в заголовке — заглавная.

## Тон

На «ты»; коротко; глаголы на кнопках; без эмодзи; без «пожалуйста» в кнопках; ошибки — что случилось и что делать («Нет сети. Карточка сохранена и дозаполнится позже»).

## Изучаемый язык

Слова, примеры и транскрипции из словаря **не** переводятся через i18n — это данные. Через i18n идёт только интерфейс.

## Проверка

- В JSX/TSX нет кириллицы вне файлов переводов.
- Все новые ключи есть в `ru`.
- Длинные строки не ломают вёрстку на узком экране (проверь 320 pt по ширине).
