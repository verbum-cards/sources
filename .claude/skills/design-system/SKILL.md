# Дизайн-система «Слово»

Значения — только в `packages/tokens/tokens.json` (собираются в `dist/tokens.ts` и `dist/tokens.css`). Полное описание — `docs/design-system.md`, живые превью — ссылка в `docs/README.md`.

## Идея

«Чернила и маркер»: бумажный фон, почти чёрный текст, один лаймовый маркер для главного. Второй акцент — мандарин. Одно главное действие на экран.

## Цвета: что и где

| Токен (TS / CSS) | Где |
|---|---|
| `paper` / `--paper` | Фон экрана |
| `surface` | Карточки, поля ввода, листы, таб-бар |
| `surfaceSunken` | Плитки статистики, дорожка прогресса (не поля ввода) |
| `line` | Декоративные разделители |
| `lineStrong` | Границы контролов (поле ввода, вторичная кнопка) |
| `ink` / `inkMuted` | Основной / вторичный текст |
| `action` + `onAction` | Главная кнопка на `paper`/`surface` — одна на экран |
| `panel` + `onPanel` + `panelMuted` | Панель главного действия дня («Повторить») |
| `highlight` + `onHighlight` | Кнопка внутри панели, активный таб, выделение — только как заливка |
| `highlightSoft` | Подложка изучаемого слова в примере, выбранный вариант |
| `signalSoft` + `signalInk` + `signal` | Мандарин: подложка, текст, иконка (серия дней, «Не помню») |
| `meter` | Заливка прогресса |
| `focus` | Кольцо фокуса 3 px с отступом 2 px |

Запрещено: hex-значения в компонентах; `highlight` как цвет текста; текст на сплошном `signal`.

## React Native

```tsx
const { colors, space, radius, type } = useTheme(); // ThemeProvider поверх @cards/tokens
<View style={{ backgroundColor: colors.surface, borderRadius: radius.lg, padding: space[6] }}>
  <Text style={[type.displayWord, { color: colors.ink }]}>{word}</Text>
</View>
```

Тема: светлая / тёмная / как в системе (`useColorScheme`), выбор сохраняется в профиле. Тень `shadowCard` — только у учебной карточки, в тёмной теме её нет.

## Веб

```css
@import '@cards/tokens/dist/tokens.css';
.card { background: var(--surface); color: var(--ink); border-radius: var(--radius-lg); }
```

Тёмная тема — по системе или через `data-theme="dark"` на корне.

## Типографика

Unbounded 600 — `displayXl` (числа), `displayL` (заголовок экрана), `displayWord` (слово на карточке). Onest — `title`, `button`, `body`, `bodyS`, `label` (капсом, до двух слов), `caption`. Длинные слова переносятся; размер шрифта не уменьшается.

## Отступы и размеры

Поля экрана `space[5]` (20), между блоками `space[4]` (16), внутри учебной карточки `space[6]` (24). Зона нажатия ≥ 44; кнопки 48, главная кнопка экрана 56. Радиусы: `lg` — карточки и панели, `md` — кнопки, поля, плитки, `pill` — чипы и прогресс, `sm` — маркер в тексте.

## Движение

Переворот карточки 280 мс ease-out; уход карточки после ответа 220 мс; нажатие — масштаб 0,98 за 120 мс. При «Уменьшить движение» (`AccessibilityInfo.isReduceMotionEnabled` / `prefers-reduced-motion`) — только смена прозрачности 150 мс. В RN — Reanimated.

## Иконки

lucide-react-native / lucide: линия 2, размер 20–22, цвет от текста. Иконка без подписи — обязательно `accessibilityLabel` / `aria-label`.

## Доступность

Контраст текста ≥ 4,5:1 (пары токенов выше уже проверены — не комбинируй их иначе без проверки); границы контролов ≥ 3:1; состояние «помню / не помню» всегда подписано словом, не только цветом.

## Тексты

На «ты», коротко; кнопки — глагол: «Повторить», «Добавить карточку»; цифры вместо слов; без эмодзи; восклицательный знак — только для достижений.

## Компоненты-эталоны

Button (primary / highlight / secondary / signal), WordInput, StudyCard, ReviewPanel, ProgressBar, Chip (default / streak / quiet), WordRow, TabBar. Новый компонент — сначала проверь, нельзя ли собрать из существующих.
