# Expo и мобильная разработка в Cards

Перед изменением конфигурации или добавлением пакета сверяйся с актуальной документацией Expo для версии SDK проекта: API модулей меняются между версиями.

## Ограничения платформ

- **iOS:** минимум 16.4 — так требует текущий Expo SDK. Не добавляй пакеты, которые поднимают минимум выше.
- **Android:** `targetSdkVersion` ≥ 36 (требование Google Play с 31.08.2026); проверяй в итоговой сборке.
- iPad не поддерживаем в бете (`ios.supportsTablet: false`).

## Конфигурация

- `ios.bundleIdentifier` и `android.package` выбирает владелец продукта; после первой загрузки в магазины не менять.
- `ios.config.usesNonExemptEncryption: false` — используем только стандартный HTTPS.
- Номер сборки и `versionCode` — автоинкремент в EAS.
- Профили `eas.json`: `development` (сборка для разработки), `preview` (внутреннее тестирование, канал EAS Update `preview`), `production` (магазины, канал `production`).
- Новые пакеты — через `npx expo install`, чтобы версия совпала с SDK.

## Локальная база (expo-sqlite)

- Схема и миграции — в `src/db/`; версия схемы — `PRAGMA user_version`; миграции только вперёд, каждая в транзакции.
- Словарь — отдельный файл базы (пакет словаря), пользовательские данные — отдельный; не смешивать.
- Все запросы — параметризованные; массовые вставки — в одной транзакции.
- Индексы под горячие запросы: поиск по префиксу леммы, карточки «к повторению сегодня».
- Тяжёлое (сборка очереди, импорт пакета) — не на главном потоке рендера; показывай прогресс.

## Безопасность

- Токены входа — в `expo-secure-store`, не в AsyncStorage и не в SQLite.
- Никаких ключей API в приложении: всё, что требует ключа (LLM, TTS), идёт через `apps/api`.

## Уведомления

`expo-notifications`: разрешение запрашиваем только на экране «Время в день и напоминания» после первой сессии, с объяснением. Одно напоминание в день; время — примерно то, когда пользователь обычно занимается.

## Бюджеты скорости и замер

| Метрика | Бюджет | Как замерить |
|---|---|---|
| Холодный старт до интерактивного главного | ≤ 1,5 с | Метка времени в начале загрузки и после первого кадра главного, релизная сборка |
| Превью слова из локального словаря | ≤ 300 мс | `performance.now()` вокруг поиска и отрисовки |
| Переход к следующей карточке | ≤ 100 мс | Метка от ответа до отрисовки следующей |

Замеряй на релизной сборке, не в режиме разработки. Цифры — в PR.

## Офлайн-проверка

Каждая пользовательская функция проверяется в авиарежиме: добавление слова из словаря, сессия, главный экран. Сеть нужна только для синхронизации, редких слов и аудио.

## Сборки для владельца продукта

- Разработка: `eas build --profile development`, затем `npx expo start`.
- Для проверки PR: `eas build --profile preview` или `eas update --channel preview` для изменений только в JavaScript.
- Опиши в PR, какая сборка нужна для проверки.
