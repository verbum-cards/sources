# Требования магазинов

Полные гайды — ссылки на документы App Store и Google Play в `docs/README.md`. Этот скилл — то, что проверяется в коде и контенте.

## Обязательно в бете

| Требование | Что проверить |
|---|---|
| Удаление аккаунта в приложении (FR-27) | Путь из профиля; перед удалением — предложение экспорта; на сервере удаляются все данные пользователя |
| Страница запроса удаления на сайте | `apps/web`: доступна без установки приложения (требование Google Play) |
| Вход через Apple | Есть везде, где есть вход через Google |
| Политика конфиденциальности | Публичная страница; ссылка в приложении (профиль) и в карточках магазинов |
| Согласованность сбора данных | Всё, что собирает код (аналитика, отчёты о сбоях, email, прогресс), описано в `docs/data-collected.md`; ответы в App Privacy и Data safety заполняются по нему |
| Разрешения | Уведомления — только после первой сессии, с объяснением; другие разрешения (камера — после беты) — с понятными текстами в `app.json` |
| Нет рекламного отслеживания | Никаких SDK рекламы и запроса ATT |
| Шифрование | Только стандартный HTTPS; `usesNonExemptEncryption: false` |
| Целевые версии | Android `targetSdkVersion` ≥ 36; iOS — актуальный Xcode SDK через EAS |
| Возрастной рейтинг | Нет общения между пользователями и пользовательского контента для других; если появится (шеринг колод, v1) — пересмотреть анкету |

## Правило для кода

Любой PR, который **добавляет сбор данных** (новое событие аналитики с личными данными, новый SDK, новое поле профиля), обязан обновить `docs/data-collected.md`. Без этого — «нужны правки».

## После беты (к публичному релизу)

- Подписки только через покупки магазинов; внешние ссылки на оплату не использовать без отдельного решения.
- Кнопка «Восстановить покупки» на экране Premium и в профиле (FR-26).
- Отмена подписки не удаляет данные: пользователь возвращается к бесплатной версии.

## Типичные причины отказа, которые ловит ревью

Падение на запуске; кнопки-заглушки «скоро будет»; нерабочая ссылка на политику конфиденциальности; нет способа войти для проверяющего; запрос разрешения без объяснения; сбор данных, не указанный в анкетах.
