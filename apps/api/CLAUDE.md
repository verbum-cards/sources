# apps/api — CLAUDE.md

Бэкенд: Node + TypeScript + PostgreSQL, модульный монолит. Общие правила — в корневом `CLAUDE.md`.

## Модули

| Модуль | Отвечает за |
|---|---|
| `auth` | Вход через Apple и Google, токены, удаление аккаунта (FR-27) |
| `sync` | Протокол из `docs/sync-protocol.md` |
| `cards` | Колоды, карточки, будущий шеринг |
| `dictionary` | Словарь, пакеты для устройства, редкие слова, очередь LLM, озвучка |
| `billing` | После беты |

Модули общаются через явные интерфейсы, не лезут в таблицы друг друга напрямую — чтобы потом выносить в отдельные сервисы.

## Стек (предложение, см. `docs/decisions.md`)

Fastify + Zod (схемы — из `@cards/contracts`), Drizzle ORM и миграции, pg-boss для очереди задач на PostgreSQL. OpenAPI генерируется из схем.

## Правила

- Все пользовательские таблицы имеют `user_id`; все запросы фильтруются по нему.
- В LLM уходят только учебные данные, без имени, email и идентификаторов пользователя.
- Секреты — в `.env`, пример — `.env.example`.
- Тесты синхронизации (симуляция двух устройств) обязательны до M2.

## Скрипты

`scripts/dictionary/` — конвейер словаря (T1.6) и импорт таблиц редактора, пока нет бэкофиса.
