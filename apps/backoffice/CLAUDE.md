# apps/backoffice — CLAUDE.md

Внутренний инструмент для редактора словаря и владельца продукта. Общие правила — в корневом `CLAUDE.md`.

## Функции (к неделям 5–6)

- Очередь проверки значений: перевод, пример и его перевод, уровень CEFR, теги; статусы `unverified → verified / rejected`.
- Редактор колод: элементы с уровнями и порядком, контекст колоды (ситуация, роли, регистр, ветки, культурные заметки — FR-49).
- Жалобы пользователей «Ошибка в карточке».
- Поддержка: найти пользователя, удалить аккаунт по запросу.

До появления бэкофиса редактор работает в таблице, импорт — скриптом в `apps/api/scripts/dictionary/`.

## Стек (предложение)

React + Vite + TypeScript, данные только через `apps/api`, вход только для ролей `editor` и `admin`. Стили — `@cards/tokens`.

## Правила

Главное — скорость работы редактора: горячие клавиши для «принять / отклонить / следующее», минимум кликов на значение. Замерять время проверки одного значения.
